# WorkBuddy connector package

Install path for WorkBuddy open platform:

1. Install runtime: `uv tool install --upgrade mdtero && mdtero setup`
2. Import this connector (`connector-meta.json` + `mcp.json` + `skills/mdtero`)
3. Or paste MCP config into `~/.workbuddy/mcp.json`

Also install via the open Agent Skills ecosystem:

```bash
npx skills add JonbinC/doi2md
```
